# Neon Audio Editor 🎛

Аудиоредактор

## Текущий функционал
- **Адаптивный неоновый UI:** Резиновое окно .
- **Spectrum EQ:** Живой эквалайзер с градиентной подсветкой частот.
- **Интерактивная волна:** Отрисовка звуковой дорожки с возможностью плавной перемотки (Drag & Drop ползунка).
- **Регулировка громкости:** Всплывающий слайдер с запоминанием состояния "Mute".
- **Воспроизведение задом наперёд (Реверс):** Математический разворот аудио с сохранением текущей позиции воспроизведения.
- **Preety Screen:** Анимированный экран загрузки при старте приложения.

## Установка и запуск
1. Скачать репозитой.
2. Необходимые библиотеки (Pygame, CustomTkinter, Pydub, Numpy).
3. **Важно для работы с MP3:** Скачайте бинарные файлы `ffmpeg.exe` и `ffprobe.exe` и положите их в корневую папку проекта (рядом с `main.py`). *Они не добавлены в репозиторий из-за большого веса и требований к кроссплатформенности.*

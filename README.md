# Neon Audio Editor 🎛️

Аудиоредактор

## Текущий функционал
- **Адаптивный неоновый UI:** Резиновое окно без искажений интерфейса при изменении размера.
- **Spectrum EQ:** Живой 15-полосный эквалайзер с градиентной подсветкой частот.
- **Интерактивная волна:** Отрисовка звуковой дорожки с возможностью плавной перемотки (Drag & Drop ползунка).
- **Умная громкость:** Всплывающий слайдер с запоминанием состояния "Mute".
- **Воспроизведение задом наперёд (Реверс):** Математический разворот аудио с автоматическим пересчетом и сохранением текущей позиции воспроизведения.
- **Splash Screen:** Анимированный экран загрузки при старте приложения.

##  Зависимости
Необходимый набор библиотек, указанны в `requirements.txt`.
